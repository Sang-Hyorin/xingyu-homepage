# Xingyu Liu — Academic Homepage

A lightweight personal academic homepage. No build step or package installation is required.

## Preview

Open `index.html` directly, or run a local web server from this folder:

```sh
python3 -m http.server 4173
```

Then visit `http://localhost:4173`.

## Update content

- Edit research areas and selected publications in `content.js`.
- Edit the biography and news in `index.html`.
- Edit research and education details in `research.html`, and honours in `awards.html`.
- `publications.html` displays publication data from `content.js`.
- Add conference photos and activity notes in `activities.html`.
- Replace `assets/xingyu-liu.jpg` to update the profile photo.
- Replace `assets/Xingyu_Liu_CV.pdf` to update the downloadable CV.

## Publish for free

The folder can be deployed as-is with GitHub Pages, Cloudflare Pages, Netlify, or Vercel.
