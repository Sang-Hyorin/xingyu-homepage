1/16 · 一个权重

只用一个可训练权重，完整走通预测、损失、求导和更新。

单独打开流程图

展开本步全部公式与说明

训练样本

x = 2，y = 6，初始 w = 2

x 是输入，y 是参考答案，w 是训练要调整的权重。

前向预测

ŷ = w × x = 2 × 2 = 4

把输入乘以当前权重，得到预测值 4。

计算损失

L = (ŷ − y)² = (4 − 6)² = 4

把预测值与参考答案的差平方，得到损失。

算梯度并更新

梯度 g = 2(wx − y)x = −8；w ← 2 − (1/16) × (−8) = 2.5

梯度为负，沿梯度反方向更新就会增大 w。本例学习率取 1/16。

再次预测

ŷ = 2.5 × 2 = 5；L = (5 − 6)² = 1

用更新后的权重再算一次，损失从 4 降到 1。下一轮可以重复这个过程。

2/16 · 两个输入、两个权重

增加一个输入和一个权重，仍然预测一个数。

单独打开流程图

展开本步全部公式与说明

输入与初始参数

x₁ = 2，x₂ = 1，目标 y = 6
w₁ = 2，w₂ = 1；η = 1/16

沿用相同的输入和目标，新增参数如本页所示。

加权求和

ŷ = w₁x₁ + w₂x₂ = 2 × 2 + 1 × 1 = 5

第一个输入贡献 4，第二个输入贡献 1。第三步会在这个加权和上加偏置。

计算损失

L = (ŷ − y)² = (5 − 6)² = 1

两个权重共同产生一个预测，所以这条样本只算一次损失。

更新两个权重

g₁ = 2(5 − 6) × 2 = −4，g₂ = 2(5 − 6) × 1 = −2

学习率仍为 1/16。两个权重分别用各自的梯度更新，从 2 和 1 变成 2.25 和 1.125。

再次预测

ŷ = 2.25 × 2 + 1.125 × 1 = 5.625

参考答案是 6，损失从 1 降到约 0.141。

3/16 · 加入偏置 bias

在加权求和后增加可训练的偏置 b。

单独打开流程图

展开本步全部公式与说明

输入与初始参数

x₁ = 2，x₂ = 1，目标 y = 6
w₁ = 2，w₂ = 1，b = 0；η = 1/16

沿用相同的输入和目标，新增参数如本页所示。

加权求和 + 偏置

z = w₁x₁ + w₂x₂ + b = 2×2 + 1×1 + 0 = 5
本步直接令 ŷ = z。

偏置 b 直接加到预测上。本例把它初始化为 0。

计算损失

L = (ŷ − y)² = (5 − 6)² = 1

参考答案还是 6。我们继续用平方误差。

更新三个参数

∂L/∂w₁ = 2(5−6)×2 = −4
∂L/∂w₂ = 2(5−6)×1 = −2
∂L/∂b = 2(5−6) = −2
(w₁, w₂, b) → (2.25, 1.125, 0.125)

b 每增加 1，预测也增加 1，所以这里乘以 1。两个权重各自用原来的梯度更新为 2.25 和 1.125。

再次预测

ŷ = 2.25 × 2 + 1.125 × 1 + 0.125 = 5.75

三个参数同时更新后，平方误差从 1 降到 0.0625。

4/16 · 加入 SiLU 激活

保留加权求和 z，在预测前插入 SiLU(z)。

单独打开流程图

展开本步全部公式与说明

① 输入 x₁、x₂ 与目标 y

x₁ = 2，x₂ = 1，目标 y = 6
初始 w₁ = 2，w₂ = 1，b = 0
学习率 η = 1/16

沿用第三步的样本、参数和学习率。

② 加权求和 + bias → z

z = w₁x₁ + w₂x₂ + b
  = 2×2 + 1×1 + 0 = 5

z 仍是加权求和的结果；w₁、w₂、b 仍是要训练的参数。

③ 新增 SiLU → 预测 ŷ

ŷ = SiLU(z) = z × σ(z)
σ(z) = 1 / (1 + e⁻ᶻ)
z = 5 → ŷ ≈ 4.9665

第三步直接令 ŷ = z；这一步在同一个 z 后面加上 SiLU。

④ 与目标比较 → 损失 L

L = (ŷ − y)²
  = (4.9665 − 6)² ≈ 1.0680

损失函数沿用前面的平方误差；使用经过 SiLU 后的预测。

⑤ 反向传播 → 三个参数的梯度

∂L/∂ŷ = 2(ŷ − 6) ≈ -2.0669
∂ŷ/∂z = σ(z) + zσ(z)(1−σ(z)) ≈ 1.0265
∂L/∂z = (∂L/∂ŷ)(∂ŷ/∂z) ≈ -2.1218
∂L/∂w₁ = (∂L/∂z)×x₁ ≈ -4.2436
∂L/∂w₂ = (∂L/∂z)×x₂ ≈ -2.1218
∂L/∂b = ∂L/∂z ≈ -2.1218

沿着 L → ŷ → z → w₁、w₂、b 反向计算。新增的 SiLU 导数乘在原来的梯度链上。

⑥ 更新 w₁、w₂、b

参数新值 = 参数旧值 − η × 对应梯度
η = 1/16
w₁ → 2.2652
w₂ → 1.1326
b → 0.1326

三个参数使用本轮算出的梯度同时更新；z 是中间结果，不是独立优化的参数。

⑦ 返回② → 再次预测与计算损失

新 z = 2w₁ + w₂ + b ≈ 5.7957
新 ŷ = SiLU(新 z) ≈ 5.7781
新 L = (新 ŷ − 6)² ≈ 0.0492
损失：1.0680 → 0.0492

返回加权求和，重复同一条流程。此处展示一次梯度下降更新。

5/16 · 增加门控支路

保留原支路，再增加 u = a₁x₁ + a₂x₂ + c，与 SiLU(z) 相乘。

单独打开流程图

展开本步全部公式与说明

输入 x₁、x₂；目标 y

x₁ = 2，x₂ = 1，目标 y = 6
原分支：w₁ = 2，w₂ = 1，b = 0
新分支：a₁ = 0.25，a₂ = 0.5，c = 0

同一组输入送入两条支路。原分支沿用上一步的初始参数。

加权求和 + bias → z

z = w₁x₁ + w₂x₂ + b
  = 2×2 + 1×1 + 0 = 5

保留原来的 z、权重和 bias。

SiLU(z)

SiLU(z) = z × σ(z)
σ(z) = 1/(1 + e⁻ᶻ)
SiLU(5) ≈ 4.9665

保留第四步的 SiLU；它的输出现在用于调节另一条支路。

新的加权求和 → u

u = a₁x₁ + a₂x₂ + c
  = 0.25×2 + 0.5×1 + 0 = 1

u 是新分支的输出，不是梯度。a₁、a₂、c 是新增的可训练参数，算法仍是你已学过的加权求和。

相乘 → ŷ = SiLU(z) × u

ŷ = SiLU(z) × u
  ≈ 4.9665 × 1 = 4.9665

新增的核心运算只有相乘。初始 u = 1，所以初始预测和第四步相同；SiLU 门控值并不局限于 0～1。

与 y 比较 → 损失 L

L = (ŷ − y)²
  = (4.9665 − 6)² ≈ 1.0680

保留原来的平方误差。

反向传播 → 两条分支的梯度

∂L/∂ŷ = 2(ŷ − 6) ≈ -2.0669

原分支：
∂L/∂z = (∂L/∂ŷ) × u × SiLU′(z) ≈ -2.1218
(∂L/∂w₁, ∂L/∂w₂, ∂L/∂b)
= (2∂L/∂z, ∂L/∂z, ∂L/∂z)

新分支：
∂L/∂u = (∂L/∂ŷ) × SiLU(z) ≈ -10.2655
(∂L/∂a₁, ∂L/∂a₂, ∂L/∂c)
= (2∂L/∂u, ∂L/∂u, ∂L/∂u)

乘法处把梯度分到两条支路：对其中一个乘数求导，就乘以另一个乘数。

更新两组权重与 bias

参数新值 = 参数旧值 − η × 对应梯度
本例 η = 1/1024
(w₁, w₂, b) → (2.0041, 1.0021, 0.0021)
(a₁, a₂, c) → (0.2700, 0.5100, 0.0100)

六个参数同时更新。新增支路的梯度较大，本例将学习率从 1/16 调小到 1/1024，避免一次更新跨得太远。

返回两条支路 → 再次预测

新 z ≈ 5.0124，新 u ≈ 1.0601
新 ŷ = SiLU(新 z) × 新 u ≈ 5.2788
损失：1.0680 → 0.5201

两条支路重新计算，再相乘、算损失、反向传播，重复训练。

6/16 · 加入输出权重

把上一页的乘积命名为中间特征 h，新增输出权重 v。

单独打开流程图

展开本步全部公式与说明

输入 x₁、x₂；目标 y

x₁ = 2，x₂ = 1，目标 y = 6
(w₁, w₂, b) = (2, 1, 0)
(a₁, a₂, c) = (0.25, 0.5, 0)
新增 v = 1；学习率 η = 1/1024

沿用第五步的样本、初始参数和学习率，只新增输出权重 v。

加权求和 + bias → z

z = w₁x₁ + w₂x₂ + b
  = 2×2 + 1×1 + 0 = 5

这一条支路完全保留。z 是计算结果，w₁、w₂、b 是参数。

SiLU(z)

SiLU(z) = z × σ(z)
σ(z) = 1/(1 + e⁻ᶻ)
SiLU(5) ≈ 4.9665

保留原来的非线性激活。

加权求和 + bias → u

u = a₁x₁ + a₂x₂ + c
  = 0.25×2 + 0.5×1 + 0 = 1

保留第五步的第二条支路；u 不是梯度。

相乘 → h = SiLU(z) × u

h = SiLU(z) × u
  ≈ 4.9665 × 1 = 4.9665

h 就是第五步直接当作预测的那个乘积。现在后面还有一步，所以把这个中间结果命名为 h；没有新增运算。

新增：输出权重 → ŷ = v × h

ŷ = v × h
初始 v = 1
ŷ = 1 × 4.9665 = 4.9665

新增一个可训练的输出权重 v，让模型学习如何缩放这个中间特征。初始 v = 1，所以预测与第五步相同。

与 y 比较 → 损失 L

L = (ŷ − y)²
  = (4.9665 − 6)² ≈ 1.0680

保留平方误差，用最后输出的 ŷ 计算损失。

反向传播 → v 及两条支路的梯度

∂L/∂ŷ = 2(ŷ − 6) ≈ -2.0669

新增输出层：
∂L/∂v = (∂L/∂ŷ) × h ≈ -10.2655
∂L/∂h = (∂L/∂ŷ) × v ≈ -2.0669

继续传到原来的两条支路：
∂L/∂z = (∂L/∂h) × u × SiLU′(z) ≈ -2.1218
∂L/∂u = (∂L/∂h) × SiLU(z) ≈ -10.2655

(∂L/∂w₁, ∂L/∂w₂, ∂L/∂b)
= (2∂L/∂z, ∂L/∂z, ∂L/∂z)
(∂L/∂a₁, ∂L/∂a₂, ∂L/∂c)
= (2∂L/∂u, ∂L/∂u, ∂L/∂u)

保留原来的反向传播，只在最前面增加穿过 v × h 的求导。z、u、h 都是中间结果。

同时更新全部七个参数

参数新值 = 参数旧值 − η × 对应梯度
η = 1/1024
v → 1.0100
(w₁, w₂, b) → (2.0041, 1.0021, 0.0021)
(a₁, a₂, c) → (0.2700, 0.5100, 0.0100)

七个参数使用同一次前向计算得到的梯度，同时更新。

返回两条支路 → 再次预测

新 z ≈ 5.0124，新 u ≈ 1.0601
新 h = SiLU(新 z) × 新 u ≈ 5.2788
新 ŷ = 新 v × 新 h ≈ 5.3317
损失：1.0680 → 0.4466

返回两条支路重新计算，再经过相乘、输出权重、损失和反向传播，继续训练。

7/16 · 扩展为两个特征通道

复制一套独立参数形成第二个并行通道，输出是两项加权和。

单独打开流程图

展开本步全部公式与说明

同一输入 x₁、x₂；目标 y

x₁ = 2，x₂ = 1，目标 y = 6
学习率 η = 1/1024

沿用第六步的样本和学习率；原来的 z、u、h、v 加下标 1，表示第一个通道。

加权求和 + bias → z₁、u₁

z₁ = w₁₁x₁ + w₁₂x₂ + b₁
   = 2×2 + 1×1 + 0 = 5
u₁ = a₁₁x₁ + a₁₂x₂ + c₁
   = 0.25×2 + 0.5×1 + 0 = 1

完全保留原来两条支路。w₁₁ 是通道 1 对输入 x₁ 的权重，w₁₂ 是通道 1 对输入 x₂ 的权重。

SiLU(z₁) × u₁ → h₁

h₁ = SiLU(z₁) × u₁
   = SiLU(5) × 1 ≈ 4.9665
初始 v₁ = 1

这就是第六步的中间结果 h，只增加了通道下标。

加权求和 + bias → z₂、u₂

z₂ = w₂₁x₁ + w₂₂x₂ + b₂
   = (−0.5)×2 + 0×1 + 0 = −1
u₂ = a₂₁x₁ + a₂₂x₂ + c₂
   = 0×2 + 1×1 + 0 = 1

新增一套相同计算，但使用独立参数。两套参数不同，才能从同一输入提取不同特征；这里的初值仅为教学演示。

SiLU(z₂) × u₂ → h₂

h₂ = SiLU(z₂) × u₂
   = SiLU(−1) × 1 ≈ -0.2689
初始 v₂ = 0.1

新增的通道也保留 SiLU 和乘法。SiLU 可以输出负数。

加权求和 → ŷ = v₁h₁ + v₂h₂

ŷ = v₁h₁ + v₂h₂
  = 1×4.9665 + 0.1×(-0.2689)
  ≈ 4.9396

原来的 v×h 现在扩展为两个通道贡献之和。它们是同一层的并行通道，不是先后两层。

与目标比较 → 损失 L

L = (ŷ − y)²
  = (4.9396 − 6)² ≈ 1.1244

仍然只有一个最终预测和一个损失，两个通道一起为降低它而训练。

反向传播 → 两个通道的梯度

令 δ = ∂L/∂ŷ = 2(ŷ − 6) ≈ -2.1207
δ 只是这段重复公式的简称。

对每个通道 i = 1 或 2：
∂L/∂vᵢ = δhᵢ
∂L/∂hᵢ = δvᵢ
∂L/∂zᵢ = δvᵢuᵢSiLU′(zᵢ)
∂L/∂uᵢ = δvᵢSiLU(zᵢ)
∂L/∂wᵢⱼ = (∂L/∂zᵢ)xⱼ
∂L/∂bᵢ = ∂L/∂zᵢ
∂L/∂aᵢⱼ = (∂L/∂uᵢ)xⱼ
∂L/∂cᵢ = ∂L/∂uᵢ

通道 1：(∂L/∂v₁, ∂L/∂z₁, ∂L/∂u₁)
≈ (-10.5326, -2.1770, -10.5326)
通道 2：(∂L/∂v₂, ∂L/∂z₂, ∂L/∂u₂)
≈ (0.5703, -0.0153, 0.0570)

每个通道都沿用第六步的求导过程。求和把梯度传给两项，再分别沿各自的计算路径回传。

同时更新全部 14 个参数

参数新值 = 参数旧值 − η × 对应梯度
η = 1/1024

通道 1：
(wᵢ₁, wᵢ₂, bᵢ) → (2.0043, 1.0021, 0.0021)
(aᵢ₁, aᵢ₂, cᵢ) → (0.2706, 0.5103, 0.0103)
vᵢ → 1.0103

通道 2：
(wᵢ₁, wᵢ₂, bᵢ) → (-0.5000, 0.0000, 0.0000)
(aᵢ₁, aᵢ₂, cᵢ) → (-0.0001, 0.9999, -0.0001)
vᵢ → 0.0994

每个通道 7 个参数，两个通道共 14 个参数；全部用更新前的梯度同时更新。

返回两个通道 → 再次预测

新 h₁ ≈ 5.2869，新 h₂ ≈ -0.2688
新 ŷ = 新 v₁×新 h₁ + 新 v₂×新 h₂
     ≈ 5.3146
损失：1.1244 → 0.4698

两个通道各自重新计算，再汇总预测、算损失和更新参数。下一步可以将这些重复计算整理为矩阵运算。

8/16 · 写成矩阵运算

不增加参数，把重复的逐通道计算组织成矩阵运算。

单独打开流程图

展开本步全部公式与说明

输入向量 x = [2, 1]ᵀ；目标 y = 6

x = [x₁, x₂]ᵀ = [2, 1]ᵀ
目标 y = 6；η = 1/1024

W = [[2, 1], [−0.5, 0]]
A = [[0.25, 0.5], [0, 1]]
b = [0, 0]ᵀ；c = [0, 0]ᵀ
v = [1, 0.1]ᵀ

把第七步的数值原样排成矩阵和向量。ᵀ 表示转置，这里把横排的列表写成列向量；W 和 A 每一行对应一个通道。

矩阵加权求和 → z = Wx + b

z = Wx + b

z₁ = 2×2 + 1×1 + 0 = 5
z₂ = (−0.5)×2 + 0×1 + 0 = −1

z = [5, −1]ᵀ
尺寸：(2×2) × (2×1) + (2×1) → (2×1)

矩阵乘法就是每一行分别与输入做加权求和。它同时写出了原来的 z₁ 和 z₂，没有新增参数。

逐元素计算 SiLU(z)

SiLU(z) = [SiLU(z₁), SiLU(z₂)]ᵀ
        ≈ [4.9665, -0.2689]ᵀ

每个元素都使用 SiLU(t) = t/(1 + e⁻ᵗ)

SiLU 分别作用于向量中的每个数，不会把两个通道混在一起。

矩阵加权求和 → u = Ax + c

u = Ax + c

u₁ = 0.25×2 + 0.5×1 + 0 = 1
u₂ = 0×2 + 1×1 + 0 = 1

u = [1, 1]ᵀ

把第七步另一条支路的两次加权求和也合写成矩阵运算。左右两列现在按支路组织，每列都包含两个通道。

逐元素相乘 → h = SiLU(z) ⊙ u

h = SiLU(z) ⊙ u

h₁ = SiLU(z₁) × u₁ ≈ 4.9665
h₂ = SiLU(z₂) × u₂ ≈ -0.2689

h ≈ [4.9665, -0.2689]ᵀ

⊙ 表示对应位置相乘：第一个乘第一个，第二个乘第二个。这一步没有加法，也不是矩阵乘法。

输出加权求和 → ŷ = vᵀh

ŷ = vᵀh
  = v₁h₁ + v₂h₂
  = 1×4.9665 + 0.1×(-0.2689)
  ≈ 4.9396

尺寸：(1×2) × (2×1) → 一个数

反向传播 → 两个样本的平均梯度

对任意参数 θ：
∂Lbatch/∂θ = (∂L₁/∂θ + ∂L₂/∂θ)/2

例如输出权重 v₁：
∂L₁/∂v₁ = 2(ŷ⁽¹⁾−6)h₁⁽¹⁾ ≈ -10.5326
∂L₂/∂v₁ = 2(ŷ⁽²⁾−4)h₁⁽²⁾ ≈ 8.5663
平均梯度 ≈ -0.9832

各样本沿用原来的完整梯度链：
δ⁽ᵏ⁾ = 2(ŷ⁽ᵏ⁾ − y⁽ᵏ⁾)
∂Lₖ/∂v = δ⁽ᵏ⁾h⁽ᵏ⁾
∂Lₖ/∂z = δ⁽ᵏ⁾v ⊙ u⁽ᵏ⁾ ⊙ SiLU′(z⁽ᵏ⁾)
∂Lₖ/∂u = δ⁽ᵏ⁾v ⊙ SiLU(z⁽ᵏ⁾)
∂Lₖ/∂W = (∂Lₖ/∂z)(x⁽ᵏ⁾)ᵀ
∂Lₖ/∂A = (∂Lₖ/∂u)(x⁽ᵏ⁾)ᵀ
∂Lₖ/∂b = ∂Lₖ/∂z；∂Lₖ/∂c = ∂Lₖ/∂u

仍然对 batch 的平均平方误差求梯度。AdamW 的权重衰减不会加进这里的梯度，也不会直接加进 m、s；之后权重变化会间接影响下一轮梯度。

保留 Adam：m、s 与起步偏差校正

沿用 Adam，对每个参数分别计算：
gₜ = 本轮平均损失的梯度
mₜ = 0.9mₜ₋₁ + 0.1gₜ
sₜ = 0.999sₜ₋₁ + 0.001gₜ²

m̂ₜ = mₜ/(1 − 0.9ᵗ)
ŝₜ = sₜ/(1 − 0.999ᵗ)
Adam 更新方向 = m̂ₜ/(√ŝₜ + ε)
ε = 10⁻⁸

第 1 轮，输出权重 v₁：
g₁ ≈ -0.9832
m̂₁ ≈ -0.9832
ŝ₁ ≈ 0.9666

这部分与第十一页完全相同。新增的权重衰减在下一节点单独作用，不经过梯度大小的缩放。

新增：Adam 更新 + 权重向零收缩

原来 Adam：
θ新 = θ旧 − η × m̂ₜ/(√ŝₜ + ε)

现在 AdamW：
θ新 = θ旧 − η × m̂ₜ/(√ŝₜ + ε) − ηλθ旧
      = (1 − ηλ)θ旧 − Adam 更新量

η = 1/1024；本例 λ = 0.01
仅收缩这一项的系数：1 − ηλ ≈ 0.9999902344

第 1 轮，以 v₁ = 1 为例：
Adam 部分将它增加约 0.0009765625
衰减部分将它减少 0.0000097656
最终 v₁ ≈ 1.0009667969

本例：W、A、v 衰减；b、c 不衰减

衰减项让正权重变小、负权重变得没那么负，都是向零靠近。总更新仍由两项共同决定，所以 v₁ 最终依然增大。λ 是人为设置的超参数，不是学出来的权重。

第 2 轮，v₁ 的 Adam 方向：
m̂₂/(√ŝ₂ + ε) ≈ -0.9976
衰减量 ηλv₁ ≈ 0.0000097751
更新后 v₁ ≈ 1.0019312562

权重衰减是正则化手段，用来约束权重规模，可能帮助泛化；效果需要看验证集。这个两样本例子只能演示怎么算，不能证明泛化改善。

验证有改善？保存参数并清零计数

新增三个状态：
best = 目前保存的最佳验证损失
bad = 连续没有明显改善的检查次数
best_params = 当时的模型参数副本

本例设置：
每次参数更新后验证一次
min_delta = 0.000001
patience = 3 次验证检查

如果 Lval < best − min_delta：
  best ← Lval；保存当前参数；bad ← 0
否则：
  bad ← bad + 1

只要 bad < 3，就返回训练流程

min_delta 规定多大的下降才算明显改善；patience 允许短暂波动。本例每次更新就验证，真实任务通常每隔若干次更新或一个 epoch 验证。计数按验证检查次数，不一定按 epoch。
