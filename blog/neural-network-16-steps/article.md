# 从一个权重到训练与推理：16 步神经网络流程图

作者：Xingyu Liu（Aitana）

[打开可点击的流程图阅读版](https://sang-hyorin.github.io/xingyu-homepage/blog/neural-network-16-steps/)

每一步保留之前的计算，只新增一个概念。流程图下方的折叠项给出每个节点的公式、数值和作用。16 是本教程的教学安排，不是模型训练固定的步骤数。

这是一套受 Qwen 前馈模块启发的**标量回归教学网络**，不是完整的 Qwen 或 Transformer：保留 bias 便于理解，使用平方误差预测数值；真实语言模型还需要 token、embedding、attention、归一化、残差连接与下一 token 的交叉熵目标。所有样本、学习率和结果均为教学演算，不是服务器实验结果。

## 如何衔接这些步骤

第 1–4 步使用学习率 1/16；第 5 步加入乘法支路后改为 1/1024，并沿用到后面。各页从标明的初始参数重新演示，**不是把上一页更新后的参数继续作为下一页的初值**。第 7–8 步是相同网络的两种写法，结果完全一致。第 9 步起使用两个训练样本。第 11–12 步分别从相同初值演示 Adam 和 AdamW。

## 1/16 · 一个权重

只用一个可训练权重，完整走通预测、损失、求导和更新。

[点击式流程图](https://sang-hyorin.github.io/xingyu-homepage/blog/neural-network-16-steps/step-01.html)

```mermaid
flowchart TD
  N0["训练样本"]
  N1["前向预测"]
  N2["计算损失"]
  N3["算梯度并更新"]
  N4["再次预测"]
  N0 --> N1
  N1 --> N2
  N2 --> N3
  N3 --> N4
  N4 -->|下一轮| N1```

<details>
<summary>1. 训练样本</summary>

```text
x = 2，y = 6，初始 w = 2
```

x 是输入，y 是参考答案，w 是训练要调整的权重。

</details>

<details>
<summary>2. 前向预测</summary>

```text
ŷ = w × x = 2 × 2 = 4
```

把输入乘以当前权重，得到预测值 4。

</details>

<details>
<summary>3. 计算损失</summary>

```text
L = (ŷ − y)² = (4 − 6)² = 4
```

把预测值与参考答案的差平方，得到损失。

</details>

<details>
<summary>4. 算梯度并更新</summary>

```text
梯度 g = 2(wx − y)x = −8；w ← 2 − (1/16) × (−8) = 2.5
```

梯度为负，沿梯度反方向更新就会增大 w。本例学习率取 1/16。

</details>

<details>
<summary>5. 再次预测</summary>

```text
ŷ = 2.5 × 2 = 5；L = (5 − 6)² = 1
```

用更新后的权重再算一次，损失从 4 降到 1。下一轮可以重复这个过程。

</details>

## 2/16 · 两个输入、两个权重

增加一个输入和一个权重，仍然预测一个数。

[点击式流程图](https://sang-hyorin.github.io/xingyu-homepage/blog/neural-network-16-steps/step-02.html)

```mermaid
flowchart TD
  N0["输入与初始参数"]
  N1["加权求和"]
  N2["计算损失"]
  N3["更新两个权重"]
  N4["再次预测"]
  N0 --> N1
  N1 --> N2
  N2 --> N3
  N3 --> N4
  N4 -->|下一轮| N1```

<details>
<summary>1. 输入与初始参数</summary>

```text
x₁ = 2，x₂ = 1，目标 y = 6
w₁ = 2，w₂ = 1；η = 1/16
```

沿用相同的输入和目标，新增参数如本页所示。

</details>

<details>
<summary>2. 加权求和</summary>

```text
ŷ = w₁x₁ + w₂x₂ = 2 × 2 + 1 × 1 = 5
```

第一个输入贡献 4，第二个输入贡献 1。第三步会在这个加权和上加偏置。

</details>

<details>
<summary>3. 计算损失</summary>

```text
L = (ŷ − y)² = (5 − 6)² = 1
```

两个权重共同产生一个预测，所以这条样本只算一次损失。

</details>

<details>
<summary>4. 更新两个权重</summary>

```text
g₁ = 2(5 − 6) × 2 = −4，g₂ = 2(5 − 6) × 1 = −2
```

学习率仍为 1/16。两个权重分别用各自的梯度更新，从 2 和 1 变成 2.25 和 1.125。

</details>

<details>
<summary>5. 再次预测</summary>

```text
ŷ = 2.25 × 2 + 1.125 × 1 = 5.625
```

参考答案是 6，损失从 1 降到约 0.141。

</details>

## 3/16 · 加入偏置 bias

在加权求和后增加可训练的偏置 b。

[点击式流程图](https://sang-hyorin.github.io/xingyu-homepage/blog/neural-network-16-steps/step-03.html)

```mermaid
flowchart TD
  N0["输入与初始参数"]
  N1["加权求和 + 偏置"]
  N2["计算损失"]
  N3["更新三个参数"]
  N4["再次预测"]
  N0 --> N1
  N1 --> N2
  N2 --> N3
  N3 --> N4
  N4 -->|下一轮| N1```

<details>
<summary>1. 输入与初始参数</summary>

```text
x₁ = 2，x₂ = 1，目标 y = 6
w₁ = 2，w₂ = 1，b = 0；η = 1/16
```

沿用相同的输入和目标，新增参数如本页所示。

</details>

<details>
<summary>2. 加权求和 + 偏置</summary>

```text
z = w₁x₁ + w₂x₂ + b = 2×2 + 1×1 + 0 = 5
本步直接令 ŷ = z。
```

偏置 b 直接加到预测上。本例把它初始化为 0。

</details>

<details>
<summary>3. 计算损失</summary>

```text
L = (ŷ − y)² = (5 − 6)² = 1
```

参考答案还是 6。我们继续用平方误差。

</details>

<details>
<summary>4. 更新三个参数</summary>

```text
∂L/∂w₁ = 2(5−6)×2 = −4
∂L/∂w₂ = 2(5−6)×1 = −2
∂L/∂b = 2(5−6) = −2
(w₁, w₂, b) → (2.25, 1.125, 0.125)
```

b 每增加 1，预测也增加 1，所以这里乘以 1。两个权重各自用原来的梯度更新为 2.25 和 1.125。

</details>

<details>
<summary>5. 再次预测</summary>

```text
ŷ = 2.25 × 2 + 1.125 × 1 + 0.125 = 5.75
```

三个参数同时更新后，平方误差从 1 降到 0.0625。

</details>


<a id="step-4"></a>

## 4/16 · 加入 SiLU 激活

保留加权求和 z，在预测前插入 SiLU(z)。

[点击式流程图](https://sang-hyorin.github.io/xingyu-homepage/blog/neural-network-16-steps/step-04.html)

```mermaid
flowchart TD
  N0["① 输入 x₁、x₂ 与目标 y"]
  N1["② 加权求和 + bias → z"]
  N2["③ 新增 SiLU → 预测 ŷ"]
  N3["④ 与目标比较 → 损失 L"]
  N4["⑤ 反向传播 → 三个参数的梯度"]
  N5["⑥ 更新 w₁、w₂、b"]
  N6["⑦ 返回② → 再次预测与计算损失"]
  N0 --> N1
  N1 --> N2
  N2 --> N3
  N3 --> N4
  N4 --> N5
  N5 --> N6
  N6 -->|下一轮| N1```

<details>
<summary>1. ① 输入 x₁、x₂ 与目标 y</summary>

```text
x₁ = 2，x₂ = 1，目标 y = 6
初始 w₁ = 2，w₂ = 1，b = 0
学习率 η = 1/16
```

沿用第三步的样本、参数和学习率。

</details>

<details>
<summary>2. ② 加权求和 + bias → z</summary>

```text
z = w₁x₁ + w₂x₂ + b
  = 2×2 + 1×1 + 0 = 5
```

z 仍是加权求和的结果；w₁、w₂、b 仍是要训练的参数。

</details>

<details>
<summary>3. ③ 新增 SiLU → 预测 ŷ</summary>

```text
ŷ = SiLU(z) = z × σ(z)
σ(z) = 1 / (1 + e⁻ᶻ)
z = 5 → ŷ ≈ 4.9665
```

第三步直接令 ŷ = z；这一步在同一个 z 后面加上 SiLU。

</details>

<details>
<summary>4. ④ 与目标比较 → 损失 L</summary>

```text
L = (ŷ − y)²
  = (4.9665 − 6)² ≈ 1.0680
```

损失函数沿用前面的平方误差；使用经过 SiLU 后的预测。

</details>

<details>
<summary>5. ⑤ 反向传播 → 三个参数的梯度</summary>

```text
∂L/∂ŷ = 2(ŷ − 6) ≈ -2.0669
∂ŷ/∂z = σ(z) + zσ(z)(1−σ(z)) ≈ 1.0265
∂L/∂z = (∂L/∂ŷ)(∂ŷ/∂z) ≈ -2.1218
∂L/∂w₁ = (∂L/∂z)×x₁ ≈ -4.2436
∂L/∂w₂ = (∂L/∂z)×x₂ ≈ -2.1218
∂L/∂b = ∂L/∂z ≈ -2.1218
```

沿着 L → ŷ → z → w₁、w₂、b 反向计算。新增的 SiLU 导数乘在原来的梯度链上。

</details>

<details>
<summary>6. ⑥ 更新 w₁、w₂、b</summary>

```text
参数新值 = 参数旧值 − η × 对应梯度
η = 1/16
w₁ → 2.2652
w₂ → 1.1326
b → 0.1326
```

三个参数使用本轮算出的梯度同时更新；z 是中间结果，不是独立优化的参数。

</details>

<details>
<summary>7. ⑦ 返回② → 再次预测与计算损失</summary>

```text
新 z = 2w₁ + w₂ + b ≈ 5.7957
新 ŷ = SiLU(新 z) ≈ 5.7781
新 L = (新 ŷ − 6)² ≈ 0.0492
损失：1.0680 → 0.0492
```

返回加权求和，重复同一条流程。此处展示一次梯度下降更新。

</details>

## 5/16 · 增加门控支路

保留原支路，再增加 u = a₁x₁ + a₂x₂ + c，与 SiLU(z) 相乘。

[点击式流程图](https://sang-hyorin.github.io/xingyu-homepage/blog/neural-network-16-steps/step-05.html)

```mermaid
flowchart TD
  N0["输入 x₁、x₂；目标 y"]
  N1["加权求和 + bias → z"]
  N2["SiLU(z)"]
  N3["新的加权求和 → u"]
  N4["相乘 → ŷ = SiLU(z) × u"]
  N5["与 y 比较 → 损失 L"]
  N6["反向传播 → 两条分支的梯度"]
  N7["更新两组权重与 bias"]
  N8["返回两条支路 → 再次预测"]
  N0 --> N1
  N0 --> N3
  N1 --> N2
  N2 --> N4
  N3 --> N4
  N4 --> N5
  N5 --> N6
  N6 --> N7
  N7 --> N8
  N8 -->|下一轮| N1
  N8 --> N3```

<details>
<summary>1. 输入 x₁、x₂；目标 y</summary>

```text
x₁ = 2，x₂ = 1，目标 y = 6
原分支：w₁ = 2，w₂ = 1，b = 0
新分支：a₁ = 0.25，a₂ = 0.5，c = 0
```

同一组输入送入两条支路。原分支沿用上一步的初始参数。

</details>

<details>
<summary>2. 加权求和 + bias → z</summary>

```text
z = w₁x₁ + w₂x₂ + b
  = 2×2 + 1×1 + 0 = 5
```

保留原来的 z、权重和 bias。

</details>

<details>
<summary>3. SiLU(z)</summary>

```text
SiLU(z) = z × σ(z)
σ(z) = 1/(1 + e⁻ᶻ)
SiLU(5) ≈ 4.9665
```

保留第四步的 SiLU；它的输出现在用于调节另一条支路。

</details>

<details>
<summary>4. 新的加权求和 → u</summary>

```text
u = a₁x₁ + a₂x₂ + c
  = 0.25×2 + 0.5×1 + 0 = 1
```

u 是新分支的输出，不是梯度。a₁、a₂、c 是新增的可训练参数，算法仍是你已学过的加权求和。

</details>

<details>
<summary>5. 相乘 → ŷ = SiLU(z) × u</summary>

```text
ŷ = SiLU(z) × u
  ≈ 4.9665 × 1 = 4.9665
```

新增的核心运算只有相乘。初始 u = 1，所以初始预测和第四步相同；SiLU 门控值并不局限于 0～1。

</details>

<details>
<summary>6. 与 y 比较 → 损失 L</summary>

```text
L = (ŷ − y)²
  = (4.9665 − 6)² ≈ 1.0680
```

保留原来的平方误差。

</details>

<details>
<summary>7. 反向传播 → 两条分支的梯度</summary>

```text
∂L/∂ŷ = 2(ŷ − 6) ≈ -2.0669

原分支：
∂L/∂z = (∂L/∂ŷ) × u × SiLU′(z) ≈ -2.1218
(∂L/∂w₁, ∂L/∂w₂, ∂L/∂b)
= (2∂L/∂z, ∂L/∂z, ∂L/∂z)

新分支：
∂L/∂u = (∂L/∂ŷ) × SiLU(z) ≈ -10.2655
(∂L/∂a₁, ∂L/∂a₂, ∂L/∂c)
= (2∂L/∂u, ∂L/∂u, ∂L/∂u)
```

乘法处把梯度分到两条支路：对其中一个乘数求导，就乘以另一个乘数。

</details>

<details>
<summary>8. 更新两组权重与 bias</summary>

```text
参数新值 = 参数旧值 − η × 对应梯度
本例 η = 1/1024
(w₁, w₂, b) → (2.0041, 1.0021, 0.0021)
(a₁, a₂, c) → (0.2700, 0.5100, 0.0100)
```

六个参数同时更新。新增支路的梯度较大，本例将学习率从 1/16 调小到 1/1024，避免一次更新跨得太远。

</details>

<details>
<summary>9. 返回两条支路 → 再次预测</summary>

```text
新 z ≈ 5.0124，新 u ≈ 1.0601
新 ŷ = SiLU(新 z) × 新 u ≈ 5.2788
损失：1.0680 → 0.5201
```

两条支路重新计算，再相乘、算损失、反向传播，重复训练。

</details>

## 6/16 · 加入输出权重

把上一页的乘积命名为中间特征 h，新增输出权重 v。

[点击式流程图](https://sang-hyorin.github.io/xingyu-homepage/blog/neural-network-16-steps/step-06.html)

```mermaid
flowchart TD
  N0["输入 x₁、x₂；目标 y"]
  N1["加权求和 + bias → z"]
  N2["SiLU(z)"]
  N3["加权求和 + bias → u"]
  N4["相乘 → h = SiLU(z) × u"]
  N5["新增：输出权重 → ŷ = v × h"]
  N6["与 y 比较 → 损失 L"]
  N7["反向传播 → v 及两条支路的梯度"]
  N8["同时更新全部七个参数"]
  N9["返回两条支路 → 再次预测"]
  N0 --> N1
  N0 --> N3
  N1 --> N2
  N2 --> N4
  N3 --> N4
  N4 --> N5
  N5 --> N6
  N6 --> N7
  N7 --> N8
  N8 --> N9
  N9 -->|下一轮| N1
  N9 --> N3```

<details>
<summary>1. 输入 x₁、x₂；目标 y</summary>

```text
x₁ = 2，x₂ = 1，目标 y = 6
(w₁, w₂, b) = (2, 1, 0)
(a₁, a₂, c) = (0.25, 0.5, 0)
新增 v = 1；学习率 η = 1/1024
```

沿用第五步的样本、初始参数和学习率，只新增输出权重 v。

</details>

<details>
<summary>2. 加权求和 + bias → z</summary>

```text
z = w₁x₁ + w₂x₂ + b
  = 2×2 + 1×1 + 0 = 5
```

这一条支路完全保留。z 是计算结果，w₁、w₂、b 是参数。

</details>

<details>
<summary>3. SiLU(z)</summary>

```text
SiLU(z) = z × σ(z)
σ(z) = 1/(1 + e⁻ᶻ)
SiLU(5) ≈ 4.9665
```

保留原来的非线性激活。

</details>

<details>
<summary>4. 加权求和 + bias → u</summary>

```text
u = a₁x₁ + a₂x₂ + c
  = 0.25×2 + 0.5×1 + 0 = 1
```

保留第五步的第二条支路；u 不是梯度。

</details>

<details>
<summary>5. 相乘 → h = SiLU(z) × u</summary>

```text
h = SiLU(z) × u
  ≈ 4.9665 × 1 = 4.9665
```

h 就是第五步直接当作预测的那个乘积。现在后面还有一步，所以把这个中间结果命名为 h；没有新增运算。

</details>

<details>
<summary>6. 新增：输出权重 → ŷ = v × h</summary>

```text
ŷ = v × h
初始 v = 1
ŷ = 1 × 4.9665 = 4.9665
```

新增一个可训练的输出权重 v，让模型学习如何缩放这个中间特征。初始 v = 1，所以预测与第五步相同。

</details>

<details>
<summary>7. 与 y 比较 → 损失 L</summary>

```text
L = (ŷ − y)²
  = (4.9665 − 6)² ≈ 1.0680
```

保留平方误差，用最后输出的 ŷ 计算损失。

</details>

<details>
<summary>8. 反向传播 → v 及两条支路的梯度</summary>

```text
∂L/∂ŷ = 2(ŷ − 6) ≈ -2.0669

新增输出层：
∂L/∂v = (∂L/∂ŷ) × h ≈ -10.2655
∂L/∂h = (∂L/∂ŷ) × v ≈ -2.0669

继续传到原来的两条支路：
∂L/∂z = (∂L/∂h) × u × SiLU′(z) ≈ -2.1218
∂L/∂u = (∂L/∂h) × SiLU(z) ≈ -10.2655

(∂L/∂w₁, ∂L/∂w₂, ∂L/∂b)
= (2∂L/∂z, ∂L/∂z, ∂L/∂z)
(∂L/∂a₁, ∂L/∂a₂, ∂L/∂c)
= (2∂L/∂u, ∂L/∂u, ∂L/∂u)
```

保留原来的反向传播，只在最前面增加穿过 v × h 的求导。z、u、h 都是中间结果。

</details>

<details>
<summary>9. 同时更新全部七个参数</summary>

```text
参数新值 = 参数旧值 − η × 对应梯度
η = 1/1024
v → 1.0100
(w₁, w₂, b) → (2.0041, 1.0021, 0.0021)
(a₁, a₂, c) → (0.2700, 0.5100, 0.0100)
```

七个参数使用同一次前向计算得到的梯度，同时更新。

</details>

<details>
<summary>10. 返回两条支路 → 再次预测</summary>

```text
新 z ≈ 5.0124，新 u ≈ 1.0601
新 h = SiLU(新 z) × 新 u ≈ 5.2788
新 ŷ = 新 v × 新 h ≈ 5.3317
损失：1.0680 → 0.4466
```

返回两条支路重新计算，再经过相乘、输出权重、损失和反向传播，继续训练。

</details>


<a id="step-7"></a>

## 7/16 · 扩展为两个特征通道

复制一套独立参数形成第二个并行通道，输出是两项加权和。

[点击式流程图](https://sang-hyorin.github.io/xingyu-homepage/blog/neural-network-16-steps/step-07.html)

```mermaid
flowchart TD
  N0["同一输入 x₁、x₂；目标 y"]
  N1["加权求和 + bias → z₁、u₁"]
  N2["SiLU(z₁) × u₁ → h₁"]
  N3["加权求和 + bias → z₂、u₂"]
  N4["SiLU(z₂) × u₂ → h₂"]
  N5["加权求和 → ŷ = v₁h₁ + v₂h₂"]
  N6["与目标比较 → 损失 L"]
  N7["反向传播 → 两个通道的梯度"]
  N8["同时更新全部 14 个参数"]
  N9["返回两个通道 → 再次预测"]
  N0 --> N1
  N0 --> N3
  N1 --> N2
  N3 --> N4
  N2 --> N5
  N4 --> N5
  N5 --> N6
  N6 --> N7
  N7 --> N8
  N8 --> N9
  N9 -->|下一轮| N1
  N9 --> N3```

<details>
<summary>1. 同一输入 x₁、x₂；目标 y</summary>

```text
x₁ = 2，x₂ = 1，目标 y = 6
学习率 η = 1/1024
```

沿用第六步的样本和学习率；原来的 z、u、h、v 加下标 1，表示第一个通道。

</details>

<details>
<summary>2. 加权求和 + bias → z₁、u₁</summary>

```text
z₁ = w₁₁x₁ + w₁₂x₂ + b₁
   = 2×2 + 1×1 + 0 = 5
u₁ = a₁₁x₁ + a₁₂x₂ + c₁
   = 0.25×2 + 0.5×1 + 0 = 1
```

完全保留原来两条支路。w₁₁ 是通道 1 对输入 x₁ 的权重，w₁₂ 是通道 1 对输入 x₂ 的权重。

</details>

<details>
<summary>3. SiLU(z₁) × u₁ → h₁</summary>

```text
h₁ = SiLU(z₁) × u₁
   = SiLU(5) × 1 ≈ 4.9665
初始 v₁ = 1
```

这就是第六步的中间结果 h，只增加了通道下标。

</details>

<details>
<summary>4. 加权求和 + bias → z₂、u₂</summary>

```text
z₂ = w₂₁x₁ + w₂₂x₂ + b₂
   = (−0.5)×2 + 0×1 + 0 = −1
u₂ = a₂₁x₁ + a₂₂x₂ + c₂
   = 0×2 + 1×1 + 0 = 1
```

新增一套相同计算，但使用独立参数。两套参数不同，才能从同一输入提取不同特征；这里的初值仅为教学演示。

</details>

<details>
<summary>5. SiLU(z₂) × u₂ → h₂</summary>

```text
h₂ = SiLU(z₂) × u₂
   = SiLU(−1) × 1 ≈ -0.2689
初始 v₂ = 0.1
```

新增的通道也保留 SiLU 和乘法。SiLU 可以输出负数。

</details>

<details>
<summary>6. 加权求和 → ŷ = v₁h₁ + v₂h₂</summary>

```text
ŷ = v₁h₁ + v₂h₂
  = 1×4.9665 + 0.1×(-0.2689)
  ≈ 4.9396
```

原来的 v×h 现在扩展为两个通道贡献之和。它们是同一层的并行通道，不是先后两层。

</details>

<details>
<summary>7. 与目标比较 → 损失 L</summary>

```text
L = (ŷ − y)²
  = (4.9396 − 6)² ≈ 1.1244
```

仍然只有一个最终预测和一个损失，两个通道一起为降低它而训练。

</details>

<details>
<summary>8. 反向传播 → 两个通道的梯度</summary>

```text
令 δ = ∂L/∂ŷ = 2(ŷ − 6) ≈ -2.1207
δ 只是这段重复公式的简称。

对每个通道 i = 1 或 2：
∂L/∂vᵢ = δhᵢ
∂L/∂hᵢ = δvᵢ
∂L/∂zᵢ = δvᵢuᵢSiLU′(zᵢ)
∂L/∂uᵢ = δvᵢSiLU(zᵢ)
∂L/∂wᵢⱼ = (∂L/∂zᵢ)xⱼ
∂L/∂bᵢ = ∂L/∂zᵢ
∂L/∂aᵢⱼ = (∂L/∂uᵢ)xⱼ
∂L/∂cᵢ = ∂L/∂uᵢ

通道 1：(∂L/∂v₁, ∂L/∂z₁, ∂L/∂u₁)
≈ (-10.5326, -2.1770, -10.5326)
通道 2：(∂L/∂v₂, ∂L/∂z₂, ∂L/∂u₂)
≈ (0.5703, -0.0153, 0.0570)
```

每个通道都沿用第六步的求导过程。求和把梯度传给两项，再分别沿各自的计算路径回传。

</details>

<details>
<summary>9. 同时更新全部 14 个参数</summary>

```text
参数新值 = 参数旧值 − η × 对应梯度
η = 1/1024

通道 1：
(wᵢ₁, wᵢ₂, bᵢ) → (2.0043, 1.0021, 0.0021)
(aᵢ₁, aᵢ₂, cᵢ) → (0.2706, 0.5103, 0.0103)
vᵢ → 1.0103

通道 2：
(wᵢ₁, wᵢ₂, bᵢ) → (-0.5000, 0.0000, 0.0000)
(aᵢ₁, aᵢ₂, cᵢ) → (-0.0001, 0.9999, -0.0001)
vᵢ → 0.0994
```

每个通道 7 个参数，两个通道共 14 个参数；全部用更新前的梯度同时更新。

</details>

<details>
<summary>10. 返回两个通道 → 再次预测</summary>

```text
新 h₁ ≈ 5.2869，新 h₂ ≈ -0.2688
新 ŷ = 新 v₁×新 h₁ + 新 v₂×新 h₂
     ≈ 5.3146
损失：1.1244 → 0.4698
```

两个通道各自重新计算，再汇总预测、算损失和更新参数。下一步可以将这些重复计算整理为矩阵运算。

</details>


<a id="step-8"></a>

## 8/16 · 写成矩阵运算

不增加参数，把重复的逐通道计算组织成矩阵运算。

[点击式流程图](https://sang-hyorin.github.io/xingyu-homepage/blog/neural-network-16-steps/step-08.html)

```mermaid
flowchart TD
  N0["输入向量 x = [2, 1]ᵀ；目标 y = 6"]
  N1["矩阵加权求和 → z = Wx + b"]
  N2["逐元素计算 SiLU(z)"]
  N3["矩阵加权求和 → u = Ax + c"]
  N4["逐元素相乘 → h = SiLU(z) ⊙ u"]
  N5["输出加权求和 → ŷ = vᵀh"]
  N6["与目标比较 → 损失 L"]
  N7["反向传播 → 梯度矩阵与向量"]
  N8["更新 W、A、b、c、v：仍然 14 个参数"]
  N9["返回矩阵运算 → 再次预测"]
  N0 --> N1
  N0 --> N3
  N1 --> N2
  N2 --> N4
  N3 --> N4
  N4 --> N5
  N5 --> N6
  N6 --> N7
  N7 --> N8
  N8 --> N9
  N9 -->|下一轮| N1
  N9 --> N3```

<details>
<summary>1. 输入向量 x = [2, 1]ᵀ；目标 y = 6</summary>

```text
x = [x₁, x₂]ᵀ = [2, 1]ᵀ
目标 y = 6；η = 1/1024

W = [[2, 1], [−0.5, 0]]
A = [[0.25, 0.5], [0, 1]]
b = [0, 0]ᵀ；c = [0, 0]ᵀ
v = [1, 0.1]ᵀ
```

把第七步的数值原样排成矩阵和向量。ᵀ 表示转置，这里把横排的列表写成列向量；W 和 A 每一行对应一个通道。

</details>

<details>
<summary>2. 矩阵加权求和 → z = Wx + b</summary>

```text
z = Wx + b

z₁ = 2×2 + 1×1 + 0 = 5
z₂ = (−0.5)×2 + 0×1 + 0 = −1

z = [5, −1]ᵀ
尺寸：(2×2) × (2×1) + (2×1) → (2×1)
```

矩阵乘法就是每一行分别与输入做加权求和。它同时写出了原来的 z₁ 和 z₂，没有新增参数。

</details>

<details>
<summary>3. 逐元素计算 SiLU(z)</summary>

```text
SiLU(z) = [SiLU(z₁), SiLU(z₂)]ᵀ
        ≈ [4.9665, -0.2689]ᵀ

每个元素都使用 SiLU(t) = t/(1 + e⁻ᵗ)
```

SiLU 分别作用于向量中的每个数，不会把两个通道混在一起。

</details>

<details>
<summary>4. 矩阵加权求和 → u = Ax + c</summary>

```text
u = Ax + c

u₁ = 0.25×2 + 0.5×1 + 0 = 1
u₂ = 0×2 + 1×1 + 0 = 1

u = [1, 1]ᵀ
```

把第七步另一条支路的两次加权求和也合写成矩阵运算。左右两列现在按支路组织，每列都包含两个通道。

</details>

<details>
<summary>5. 逐元素相乘 → h = SiLU(z) ⊙ u</summary>

```text
h = SiLU(z) ⊙ u

h₁ = SiLU(z₁) × u₁ ≈ 4.9665
h₂ = SiLU(z₂) × u₂ ≈ -0.2689

h ≈ [4.9665, -0.2689]ᵀ
```

⊙ 表示对应位置相乘：第一个乘第一个，第二个乘第二个。这一步没有加法，也不是矩阵乘法。

</details>

<details>
<summary>6. 输出加权求和 → ŷ = vᵀh</summary>

```text
ŷ = vᵀh
  = v₁h₁ + v₂h₂
  = 1×4.9665 + 0.1×(-0.2689)
  ≈ 4.9396

尺寸：(1×2) × (2×1) → 一个数
```

这就是上一页的输出加权求和，现在写成向量内积。在这里，两个通道的贡献被合并成最终预测。

</details>

<details>
<summary>7. 与目标比较 → 损失 L</summary>

```text
L = (ŷ − y)²
  = (4.9396 − 6)² ≈ 1.1244
```

仍然只有一个最终预测和一个损失，两个通道一起为降低它而训练。

</details>

<details>
<summary>8. 反向传播 → 梯度矩阵与向量</summary>

```text
δ = ∂L/∂ŷ = 2(ŷ − 6) ≈ -2.1207
∂L/∂v = δh
∂L/∂h = δv

∂L/∂z = (δv) ⊙ u ⊙ SiLU′(z)
        ≈ [-2.1770, -0.0153]ᵀ
∂L/∂u = (δv) ⊙ SiLU(z)
        ≈ [-10.5326, 0.0570]ᵀ

∂L/∂W = (∂L/∂z)xᵀ
≈ [[-4.3540, -2.1770],
    [-0.0307, -0.0153]]
∂L/∂A = (∂L/∂u)xᵀ
≈ [[-21.0652, -10.5326],
    [0.1141, 0.0570]]
∂L/∂b = ∂L/∂z；∂L/∂c = ∂L/∂u
```

梯度公式与第七步逐项相同。(∂L/∂z)xᵀ 是列向量乘行向量，得到 2×2 的梯度矩阵；每个元素仍然是对应梯度乘对应输入。

</details>

<details>
<summary>9. 更新 W、A、b、c、v：仍然 14 个参数</summary>

```text
每组参数 Θ ← Θ − η(∂L/∂Θ)
η = 1/1024；Θ 依次取 W、A、b、c、v

新 W ≈ [[2.0043, 1.0021],
             [-0.5000, 0.0000]]
新 A ≈ [[0.2706, 0.5103],
             [-0.0001, 0.9999]]
新 b ≈ [0.0021, 0.0000]ᵀ
新 c ≈ [0.0103, -0.0001]ᵀ
新 v ≈ [1.0103, 0.0994]ᵀ
```

W 有 4 个数，A 有 4 个数，b、c、v 各有 2 个数，共 14 个参数。矩阵只是把原来的参数放在一起计算。

</details>

<details>
<summary>10. 返回矩阵运算 → 再次预测</summary>

```text
新 z = 新 W × x + 新 b
新 u = 新 A × x + 新 c
新 h = SiLU(新 z) ⊙ 新 u
新 ŷ = 新 vᵀ × 新 h ≈ 5.3146

损失：1.1244 → 0.4698
与第七步的结果相同
```

矩阵形式便于把大量通道一起交给 GPU 计算。网络仍是原来的网络，本步只改变计算的组织方式。

</details>


<a id="step-9"></a>

## 9/16 · mini-batch 与平均梯度

网络不变，新增第二个训练样本，用平均梯度统一更新一次。

[点击式流程图](https://sang-hyorin.github.io/xingyu-homepage/blog/neural-network-16-steps/step-09.html)

```mermaid
flowchart TD
  N0["新增第二个样本 → 一个 batch"]
  N1["每个样本：z = Wx + b"]
  N2["逐元素 SiLU(z)"]
  N3["每个样本：u = Ax + c"]
  N4["每个样本：h = SiLU(z) ⊙ u"]
  N5["每个样本：ŷ = vᵀh"]
  N6["新增：两个样本的损失取平均"]
  N7["反向传播 → 两个样本的平均梯度"]
  N8["更新同一组 14 个参数，一次"]
  N9["再次预测两个样本 → 检查平均损失"]
  N0 --> N1
  N0 --> N3
  N1 --> N2
  N2 --> N4
  N3 --> N4
  N4 --> N5
  N5 --> N6
  N6 --> N7
  N7 --> N8
  N8 --> N9
  N9 -->|下一轮| N1
  N9 --> N3```

<details>
<summary>1. 新增第二个样本 → 一个 batch</summary>

```text
样本 1（保留）：x⁽¹⁾ = [2, 1]ᵀ，y⁽¹⁾ = 6
样本 2（新增）：x⁽²⁾ = [1, 2]ᵀ，y⁽²⁾ = 4
batch size = 2；η = 1/1024

W = [[2, 1], [−0.5, 0]]
A = [[0.25, 0.5], [0, 1]]
b = c = [0, 0]ᵀ；v = [1, 0.1]ᵀ
```

括号上标 (1)、(2) 表示样本编号，不是乘方。网络和初始参数沿用第八步；新增的是第二个教学样本。

</details>

<details>
<summary>2. 每个样本：z = Wx + b</summary>

```text
z⁽ᵏ⁾ = Wx⁽ᵏ⁾ + b

样本 1：
z = [5.0000, -1.0000]ᵀ

样本 2：
z = [4.0000, -0.5000]ᵀ
```

W 和 b 只有一份。每个样本把自己的输入送入相同的加权求和。

</details>

<details>
<summary>3. 逐元素 SiLU(z)</summary>

```text
每个样本分别计算 SiLU(z)

样本 1：
SiLU(z) = [4.9665, -0.2689]ᵀ

样本 2：
SiLU(z) = [3.9281, -0.1888]ᵀ
```

激活仍然逐元素进行，两个样本之间不会在这里混合。

</details>

<details>
<summary>4. 每个样本：u = Ax + c</summary>

```text
u⁽ᵏ⁾ = Ax⁽ᵏ⁾ + c

样本 1：
u = [1.0000, 1.0000]ᵀ

样本 2：
u = [1.2500, 2.0000]ᵀ
```

另一条支路也保持不变；两个样本共用 A 和 c。

</details>

<details>
<summary>5. 每个样本：h = SiLU(z) ⊙ u</summary>

```text
h⁽ᵏ⁾ = SiLU(z⁽ᵏ⁾) ⊙ u⁽ᵏ⁾

样本 1：
h = [4.9665, -0.2689]ᵀ

样本 2：
h = [4.9101, -0.3775]ᵀ
```

每个样本内部的对应通道相乘，仍然保留两个特征通道。

</details>

<details>
<summary>6. 每个样本：ŷ = vᵀh</summary>

```text
ŷ⁽ᵏ⁾ = vᵀh⁽ᵏ⁾

样本 1：
预测 ŷ = 4.9396；目标 y = 6

样本 2：
预测 ŷ = 4.8723；目标 y = 4
```

同一组输出权重 v，为两个样本分别产生一个预测。

</details>

<details>
<summary>7. 新增：两个样本的损失取平均</summary>

```text
L₁ = (ŷ⁽¹⁾ − 6)² ≈ 1.1244
L₂ = (ŷ⁽²⁾ − 4)² ≈ 0.7609

Lbatch = (L₁ + L₂)/2 ≈ 0.9426
```

新增的核心步骤：先各自计算误差的平方，再取平均。不能先平均预测误差再平方，否则正负误差可能抵消。

</details>

<details>
<summary>8. 反向传播 → 两个样本的平均梯度</summary>

```text
对任意参数 θ：
∂Lbatch/∂θ = (∂L₁/∂θ + ∂L₂/∂θ)/2

例如输出权重 v₁：
∂L₁/∂v₁ = 2(ŷ⁽¹⁾−6)h₁⁽¹⁾ ≈ -10.5326
∂L₂/∂v₁ = 2(ŷ⁽²⁾−4)h₁⁽²⁾ ≈ 8.5663
平均梯度 ≈ -0.9832

各样本沿用原来的完整梯度链：
δ⁽ᵏ⁾ = 2(ŷ⁽ᵏ⁾ − y⁽ᵏ⁾)
∂Lₖ/∂v = δ⁽ᵏ⁾h⁽ᵏ⁾
∂Lₖ/∂z = δ⁽ᵏ⁾v ⊙ u⁽ᵏ⁾ ⊙ SiLU′(z⁽ᵏ⁾)
∂Lₖ/∂u = δ⁽ᵏ⁾v ⊙ SiLU(z⁽ᵏ⁾)
∂Lₖ/∂W = (∂Lₖ/∂z)(x⁽ᵏ⁾)ᵀ
∂Lₖ/∂A = (∂Lₖ/∂u)(x⁽ᵏ⁾)ᵀ
∂Lₖ/∂b = ∂Lₖ/∂z；∂Lₖ/∂c = ∂Lₖ/∂u
```

两个样本的梯度都在同一组旧参数上计算，再平均。实现时也可以直接对平均损失做一次反向传播，结果相同。

</details>

<details>
<summary>9. 更新同一组 14 个参数，一次</summary>

```text
Θ新 = Θ旧 − η × 平均梯度
η = 1/1024

新 W ≈ [[2.0010, 0.9988],
 [-0.5000, -0.0001]]
新 A ≈ [[0.2569, 0.4985],
 [-0.0000, 1.0000]]
新 b ≈ [-0.0001, -0.0000]ᵀ
新 c ≈ [0.0018, -0.0000]ᵀ
新 v ≈ [1.0010, 0.1000]ᵀ
```

同一组 14 个参数只更新一次。不是先用样本 1 更新，再用新参数计算样本 2；那是不同的训练过程。

</details>

<details>
<summary>10. 再次预测两个样本 → 检查平均损失</summary>

```text
样本 1：预测 4.9396 → 5.0154
损失 1.1244 → 0.9694

样本 2：预测 4.8723 → 4.8973
损失 0.7609 → 0.8051

平均损失：0.9426 → 0.8873
```

优化目标是整个 batch 的平均损失，不保证每个样本每次都变好。这里用原 batch 检查一次更新；真实训练通常继续取下一个 batch。

</details>


<a id="step-10"></a>

## 10/16 · SGD 动量

保存历史梯度方向，让当前更新参考过去的方向。

[点击式流程图](https://sang-hyorin.github.io/xingyu-homepage/blog/neural-network-16-steps/step-10.html)

```mermaid
flowchart TD
  N0["保留两个样本 → 一个 batch"]
  N1["每个样本：z = Wx + b"]
  N2["逐元素 SiLU(z)"]
  N3["每个样本：u = Ax + c"]
  N4["每个样本：h = SiLU(z) ⊙ u"]
  N5["每个样本：ŷ = vᵀh"]
  N6["两个样本的损失取平均"]
  N7["反向传播 → 两个样本的平均梯度"]
  N8["新增：动量 m = 0.9 × 旧 m + 当前梯度"]
  N9["用动量更新同一组 14 个参数"]
  N10["重复流程 → 看第二轮的动量作用"]
  N0 --> N1
  N0 --> N3
  N1 --> N2
  N2 --> N4
  N3 --> N4
  N4 --> N5
  N5 --> N6
  N6 --> N7
  N7 --> N8
  N8 --> N9
  N9 --> N10
  N10 -->|下一轮| N1
  N10 --> N3```

<details>
<summary>1. 保留两个样本 → 一个 batch</summary>

```text
样本 1（保留）：x⁽¹⁾ = [2, 1]ᵀ，y⁽¹⁾ = 6

<details>
<summary>8. 反向传播 → 两个样本的平均梯度</summary>

```text
对任意参数 θ：
∂Lbatch/∂θ = (∂L₁/∂θ + ∂L₂/∂θ)/2

例如输出权重 v₁：
∂L₁/∂v₁ = 2(ŷ⁽¹⁾−6)h₁⁽¹⁾ ≈ -10.5326
∂L₂/∂v₁ = 2(ŷ⁽²⁾−4)h₁⁽²⁾ ≈ 8.5663
平均梯度 ≈ -0.9832

各样本沿用原来的完整梯度链：
δ⁽ᵏ⁾ = 2(ŷ⁽ᵏ⁾ − y⁽ᵏ⁾)
∂Lₖ/∂v = δ⁽ᵏ⁾h⁽ᵏ⁾
∂Lₖ/∂z = δ⁽ᵏ⁾v ⊙ u⁽ᵏ⁾ ⊙ SiLU′(z⁽ᵏ⁾)
∂Lₖ/∂u = δ⁽ᵏ⁾v ⊙ SiLU(z⁽ᵏ⁾)
∂Lₖ/∂W = (∂Lₖ/∂z)(x⁽ᵏ⁾)ᵀ
∂Lₖ/∂A = (∂Lₖ/∂u)(x⁽ᵏ⁾)ᵀ
∂Lₖ/∂b = ∂Lₖ/∂z；∂Lₖ/∂c = ∂Lₖ/∂u
```

仍按第九步的方法求平均梯度。动量不改变损失函数或求导方式，只改变接下来如何使用这个梯度。

</details>

<details>
<summary>9. 新增：动量 m = 0.9 × 旧 m + 当前梯度</summary>

```text
对每一个参数分别保存动量：
mₜ = βmₜ₋₁ + gₜ
β = 0.9；m₀ = 0
gₜ = 本轮 batch 的平均梯度

以输出权重 v₁ 为例：
第 1 轮 g₁ ≈ -0.9832
m₁ = 0.9×0 + g₁ ≈ -0.9832

第 2 轮 g₂ ≈ -0.5358
m₂ = 0.9m₁ + g₂ ≈ -1.4206
```

m 是优化器记住的累计方向，不是新的网络权重，也不参与预测。每个参数都有自己的 m；这里采用普通 SGD momentum 的累加写法。

</details>

<details>
<summary>10. 用动量更新同一组 14 个参数</summary>

```text
参数更新改为：Θ新 = Θ旧 − ηmₜ
η = 1/1024

第 1 轮：m₁ = g₁，所以与第九步相同
新 W ≈ [[2.0010, 0.9988],
 [-0.5000, -0.0001]]
新 A ≈ [[0.2569, 0.4985],
 [-0.0000, 1.0000]]
新 b ≈ [-0.0001, -0.0000]ᵀ
新 c ≈ [0.0018, -0.0000]ᵀ
新 v ≈ [1.0010, 0.1000]ᵀ

第 2 轮，以 v₁ 为例：
v₁ = 1.0010 − (1/1024)×(-1.4206)
   ≈ 1.0023
```

原来直接减去学习率乘当前梯度；现在减去学习率乘累计动量。14 个参数仍然同时更新，并保留各自的动量供下一轮使用。

</details>

<details>
<summary>11. 重复流程 → 看第二轮的动量作用</summary>

```text
本例重复同一个 batch 两轮：
平均损失 0.9426 → 0.8873 → 0.8014

第 2 轮的 v₁：
当前梯度 g₂ ≈ -0.5358
历史贡献 0.9m₁ ≈ -0.8849
实际使用 m₂ ≈ -1.4206

相同初值与学习率、两轮普通 SGD：
平均损失 ≈ 0.8416
```

本例连续两轮的方向相近，动量加强了更新。方向相反时，历史贡献也可能阻碍转向；动量并不保证每次更好。真实训练可以换下一个 batch，动量仍会保留。

</details>

ŝ₁ = g₁² ≈ 0.9666
v₁新 = 1 − η × g₁/(|g₁| + ε)

另一个参数 w₁₁：
当前梯度 ≈ -1.0292
w₁₁新 ≈ 2.00098
```

mₜ = 0.9mₜ₋₁ + 0.1gₜ
sₜ = 0.999sₜ₋₁ + 0.001gₜ²

m̂ₜ = mₜ/(1 − 0.9ᵗ)
ŝₜ = sₜ/(1 − 0.999ᵗ)
Adam 更新方向 = m̂ₜ/(√ŝₜ + ε)
ε = 10⁻⁸

第 1 轮，输出权重 v₁：
g₁ ≈ -0.9832
m̂₁ ≈ -0.9832
ŝ₁ ≈ 0.9666
```

这部分与第十一页完全相同。新增的权重衰减在下一节点单独作用，不经过梯度大小的缩放。

</details>

<details>
<summary>10. 新增：Adam 更新 + 权重向零收缩</summary>

```text
原来 Adam：
θ新 = θ旧 − η × m̂ₜ/(√ŝₜ + ε)

现在 AdamW：
θ新 = θ旧 − η × m̂ₜ/(√ŝₜ + ε) − ηλθ旧
      = (1 − ηλ)θ旧 − Adam 更新量

η = 1/1024；本例 λ = 0.01
仅收缩这一项的系数：1 − ηλ ≈ 0.9999902344

第 1 轮，以 v₁ = 1 为例：
Adam 部分将它增加约 0.0009765625
衰减部分将它减少 0.0000097656
最终 v₁ ≈ 1.0009667969

本例：W、A、v 衰减；b、c 不衰减
```

衰减项让正权重变小、负权重变得没那么负，都是向零靠近。总更新仍由两项共同决定，所以 v₁ 最终依然增大。λ 是人为设置的超参数，不是学出来的权重。

</details>

<details>
<summary>11. 重复完整流程 → 再次预测</summary>

```text

平均损失 0.942647 → 0.929028 → 0.915593

第 2 轮，v₁ 的 Adam 方向：

衰减量 ηλv₁ ≈ 0.0000097751
更新后 v₁ ≈ 1.0019312562
```

权重衰减是正则化手段，用来约束权重规模，可能帮助泛化；效果需要看验证集。这个两样本例子只能演示怎么算，不能证明泛化改善。

</details>

<details>
<summary>7. 两个样本的损失取平均</summary>

```text
L₁ = (ŷ⁽¹⁾ − 6)² ≈ 1.1244
L₂ = (ŷ⁽²⁾ − 4)² ≈ 0.7609

Lbatch = (L₁ + L₂)/2 ≈ 0.9426
```

新增的核心步骤：先各自计算误差的平方，再取平均。不能先平均预测误差再平方，否则正负误差可能抵消。

</details>

<details>
<summary>8. 反向传播 → 两个样本的平均梯度</summary>

```text
对任意参数 θ：
∂Lbatch/∂θ = (∂L₁/∂θ + ∂L₂/∂θ)/2

例如输出权重 v₁：
∂L₁/∂v₁ = 2(ŷ⁽¹⁾−6)h₁⁽¹⁾ ≈ -10.5326
∂L₂/∂v₁ = 2(ŷ⁽²⁾−4)h₁⁽²⁾ ≈ 8.5663
平均梯度 ≈ -0.9832

各样本沿用原来的完整梯度链：
δ⁽ᵏ⁾ = 2(ŷ⁽ᵏ⁾ − y⁽ᵏ⁾)
∂Lₖ/∂v = δ⁽ᵏ⁾h⁽ᵏ⁾
∂Lₖ/∂z = δ⁽ᵏ⁾v ⊙ u⁽ᵏ⁾ ⊙ SiLU′(z⁽ᵏ⁾)
∂Lₖ/∂u = δ⁽ᵏ⁾v ⊙ SiLU(z⁽ᵏ⁾)
∂Lₖ/∂W = (∂Lₖ/∂z)(x⁽ᵏ⁾)ᵀ
∂Lₖ/∂A = (∂Lₖ/∂u)(x⁽ᵏ⁾)ᵀ
∂Lₖ/∂b = ∂Lₖ/∂z；∂Lₖ/∂c = ∂Lₖ/∂u
```

仍然对 batch 的平均平方误差求梯度。AdamW 的权重衰减不会加进这里的梯度，也不会直接加进 m、s；之后权重变化会间接影响下一轮梯度。

</details>

<details>
<summary>9. 保留 Adam：m、s 与起步偏差校正</summary>

```text
沿用 Adam，对每个参数分别计算：
gₜ = 本轮平均损失的梯度
mₜ = 0.9mₜ₋₁ + 0.1gₜ
sₜ = 0.999sₜ₋₁ + 0.001gₜ²

m̂ₜ = mₜ/(1 − 0.9ᵗ)
ŝₜ = sₜ/(1 − 0.999ᵗ)
Adam 更新方向 = m̂ₜ/(√ŝₜ + ε)
ε = 10⁻⁸

第 1 轮，输出权重 v₁：
g₁ ≈ -0.9832
m̂₁ ≈ -0.9832
ŝ₁ ≈ 0.9666
```

这部分与第十一页完全相同。新增的权重衰减在下一节点单独作用，不经过梯度大小的缩放。

</details>

<details>
<summary>10. 保留 AdamW：更新参数 + 权重衰减</summary>

```text
原来 Adam：
θ新 = θ旧 − η × m̂ₜ/(√ŝₜ + ε)

现在 AdamW：
θ新 = θ旧 − η × m̂ₜ/(√ŝₜ + ε) − ηλθ旧
      = (1 − ηλ)θ旧 − Adam 更新量

η = 1/1024；本例 λ = 0.01
仅收缩这一项的系数：1 − ηλ ≈ 0.9999902344

第 1 轮，以 v₁ = 1 为例：
Adam 部分将它增加约 0.0009765625
衰减部分将它减少 0.0000097656
最终 v₁ ≈ 1.0009667969

本例：W、A、v 衰减；b、c 不衰减
```

衰减项让正权重变小、负权重变得没那么负，都是向零靠近。总更新仍由两项共同决定，所以 v₁ 最终依然增大。λ 是人为设置的超参数，不是学出来的权重。

</details>

<details>
<summary>11. 重复训练流程 → 记录训练损失</summary>

```text

第 2 轮，v₁ 的 Adam 方向：
m̂₂/(√ŝ₂ + ε) ≈ -0.9976
衰减量 ηλv₁ ≈ 0.0000097751
更新后 v₁ ≈ 1.0019312562
```

```

训练仍使用原来的两个样本，验证仍使用 [1.5, 1.5]ᵀ → 5。本页另列两个测试样本，只在最佳检查点确定后评估；前面的梯度和早停计算均未使用它们。真实实验应在开始前划分并隔离测试集。

</details>

<details>
<summary>2. 每个样本：z = Wx + b</summary>

```text
z⁽ᵏ⁾ = Wx⁽ᵏ⁾ + b

样本 1：
z = [5.0000, -1.0000]ᵀ

样本 2：
z = [4.0000, -0.5000]ᵀ
```

W 和 b 只有一份。每个样本把自己的输入送入相同的加权求和。

</details>

<details>
<summary>3. 逐元素 SiLU(z)</summary>

```text
每个样本分别计算 SiLU(z)

样本 1：
SiLU(z) = [4.9665, -0.2689]ᵀ

样本 2：
SiLU(z) = [3.9281, -0.1888]ᵀ
```

激活仍然逐元素进行，两个样本之间不会在这里混合。

</details>

<details>
<summary>4. 每个样本：u = Ax + c</summary>

```text
u⁽ᵏ⁾ = Ax⁽ᵏ⁾ + c

样本 1：
u = [1.0000, 1.0000]ᵀ

样本 2：
u = [1.2500, 2.0000]ᵀ
```

另一条支路也保持不变；两个样本共用 A 和 c。

</details>

<details>
<summary>5. 每个样本：h = SiLU(z) ⊙ u</summary>

```text
h⁽ᵏ⁾ = SiLU(z⁽ᵏ⁾) ⊙ u⁽ᵏ⁾

样本 1：
h = [4.9665, -0.2689]ᵀ

样本 2：
h = [4.9101, -0.3775]ᵀ
```

每个样本内部的对应通道相乘，仍然保留两个特征通道。

</details>

<details>
<summary>6. 每个样本：ŷ = vᵀh</summary>

```text
ŷ⁽ᵏ⁾ = vᵀh⁽ᵏ⁾

样本 1：
预测 ŷ = 4.9396；目标 y = 6

样本 2：
预测 ŷ = 4.8723；目标 y = 4
```

同一组输出权重 v，为两个样本分别产生一个预测。

</details>

<details>
<summary>7. 两个样本的损失取平均</summary>

```text
L₁ = (ŷ⁽¹⁾ − 6)² ≈ 1.1244
L₂ = (ŷ⁽²⁾ − 4)² ≈ 0.7609

Lbatch = (L₁ + L₂)/2 ≈ 0.9426
```

新增的核心步骤：先各自计算误差的平方，再取平均。不能先平均预测误差再平方，否则正负误差可能抵消。

</details>

<details>
<summary>8. 反向传播 → 两个样本的平均梯度</summary>

```text
对任意参数 θ：
∂Lbatch/∂θ = (∂L₁/∂θ + ∂L₂/∂θ)/2

例如输出权重 v₁：
∂L₁/∂v₁ = 2(ŷ⁽¹⁾−6)h₁⁽¹⁾ ≈ -10.5326
∂L₂/∂v₁ = 2(ŷ⁽²⁾−4)h₁⁽²⁾ ≈ 8.5663
平均梯度 ≈ -0.9832

各样本沿用原来的完整梯度链：
δ⁽ᵏ⁾ = 2(ŷ⁽ᵏ⁾ − y⁽ᵏ⁾)
∂Lₖ/∂v = δ⁽ᵏ⁾h⁽ᵏ⁾
∂Lₖ/∂z = δ⁽ᵏ⁾v ⊙ u⁽ᵏ⁾ ⊙ SiLU′(z⁽ᵏ⁾)
∂Lₖ/∂u = δ⁽ᵏ⁾v ⊙ SiLU(z⁽ᵏ⁾)
∂Lₖ/∂W = (∂Lₖ/∂z)(x⁽ᵏ⁾)ᵀ
∂Lₖ/∂A = (∂Lₖ/∂u)(x⁽ᵏ⁾)ᵀ
∂Lₖ/∂b = ∂Lₖ/∂z；∂Lₖ/∂c = ∂Lₖ/∂u
```

仍然对 batch 的平均平方误差求梯度。AdamW 的权重衰减不会加进这里的梯度，也不会直接加进 m、s；之后权重变化会间接影响下一轮梯度。

</details>

<details>
<summary>9. 保留 Adam：m、s 与起步偏差校正</summary>

```text
沿用 Adam，对每个参数分别计算：
gₜ = 本轮平均损失的梯度
mₜ = 0.9mₜ₋₁ + 0.1gₜ
sₜ = 0.999sₜ₋₁ + 0.001gₜ²

m̂ₜ = mₜ/(1 − 0.9ᵗ)
ŝₜ = sₜ/(1 − 0.999ᵗ)
Adam 更新方向 = m̂ₜ/(√ŝₜ + ε)
ε = 10⁻⁸

第 1 轮，输出权重 v₁：
g₁ ≈ -0.9832
m̂₁ ≈ -0.9832
ŝ₁ ≈ 0.9666
```

这部分与第十一页完全相同。新增的权重衰减在下一节点单独作用，不经过梯度大小的缩放。

</details>

<details>
<summary>10. 保留 AdamW：更新参数 + 权重衰减</summary>

```text
原来 Adam：
θ新 = θ旧 − η × m̂ₜ/(√ŝₜ + ε)

现在 AdamW：
θ新 = θ旧 − η × m̂ₜ/(√ŝₜ + ε) − ηλθ旧
      = (1 − ηλ)θ旧 − Adam 更新量

η = 1/1024；本例 λ = 0.01
仅收缩这一项的系数：1 − ηλ ≈ 0.9999902344

第 1 轮，以 v₁ = 1 为例：
Adam 部分将它增加约 0.0009765625
衰减部分将它减少 0.0000097656
最终 v₁ ≈ 1.0009667969

本例：W、A、v 衰减；b、c 不衰减
```

衰减项让正权重变小、负权重变得没那么负，都是向零靠近。总更新仍由两项共同决定，所以 v₁ 最终依然增大。λ 是人为设置的超参数，不是学出来的权重。

</details>

<details>
<summary>11. 重复训练流程 → 记录训练损失</summary>

```text
同一个 batch 连续更新两轮：
平均损失 0.942647 → 0.929028 → 0.915593

第 2 轮，v₁ 的 Adam 方向：
m̂₂/(√ŝ₂ + ε) ≈ -0.9976
衰减量 ηλv₁ ≈ 0.0000097751
更新后 v₁ ≈ 1.0019312562
```

权重衰减是正则化手段，用来约束权重规模，可能帮助泛化；效果需要看验证集。这个两样本例子只能演示怎么算，不能证明泛化改善。

</details>

<details>
<summary>12. 保留验证：新样本 → 同一网络 → 验证损失</summary>

```text
新增验证样本：x = [1.5, 1.5]ᵀ，目标 y = 5
使用训练两轮后的参数，执行同一条前向流程：

z = Wx + b ≈ [4.4980, -0.7578]ᵀ
u = Ax + c ≈ [1.1269, 1.4980]ᵀ
h = SiLU(z) ⊙ u ≈ [5.0131, -0.3623]ᵀ
ŷ = vᵀh ≈ 4.9858
Lval = (ŷ − 5)² ≈ 0.000201

到这里结束：不算梯度，不更新 W、A、b、c、v
也不更新 AdamW 的 m、s
```

验证使用相同的模型，但这个样本从未参与训练更新。真实验证集通常包含许多独立样本，报告它们的平均损失；仅一个样本无法可靠判断泛化。

</details>

<details>
<summary>13. 比较两条损失 → 查看变化趋势</summary>

```text
本例的损失记录：
初始：训练 0.942647；验证 0.000853
第 1 轮：训练 0.929028；验证 0.000470
第 2 轮：训练 0.915593；验证 0.000201

观察随训练变化的趋势：
训练下降、验证也下降 → 可能正在学到可泛化规律
训练下降、验证持续上升 → 过拟合警示

可以按预先约定的验证指标，保留表现最好的检查点
```

验证集可用于选择训练轮数或 λ 等超参数，但不能作为训练样本回传梯度。反复选方案也会间接适应验证集，最终结论还需要独立测试集。两条损失之间没有通用的“合格差值”。

</details>

<details>
<summary>14. 验证有改善？保存参数并清零计数</summary>

```text
新增三个状态：
best = 目前保存的最佳验证损失
bad = 连续没有明显改善的检查次数
best_params = 当时的模型参数副本

本例设置：
每次参数更新后验证一次
min_delta = 0.000001
patience = 3 次验证检查

如果 Lval < best − min_delta：
  best ← Lval；保存当前参数；bad ← 0
否则：
  bad ← bad + 1

只要 bad < 3，就返回训练流程
```

min_delta 规定多大的下降才算明显改善；patience 允许短暂波动。本例每次更新就验证，真实任务通常每隔若干次更新或一个 epoch 验证。计数按验证检查次数，不一定按 epoch。

</details>

<details>
<summary>15. 连续 3 次无改善 → 停止并恢复最佳参数</summary>

```text
沿用本例数据与 AdamW，实际计算得到：
更新轮次 | 训练损失 | 验证损失 | bad
1 | 0.929028 | 0.000470 | 0（保存）
2 | 0.915593 | 0.000201 | 0（保存）
3 | 0.902344 | 0.000045 | 0（保存）
4 | 0.889285 | 0.000000 | 0（保存）
5 | 0.876417 | 0.000063 | 1
6 | 0.863742 | 0.000228 | 2
7 | 0.851259 | 0.000488 | 3

第 7 次更新后达到 patience，停止。
恢复第 4 次更新后的参数：
训练损失 ≈ 0.889285
验证损失 ≈ 0.000000
```

停止时的参数不一定最好，所以恢复保存的检查点。这里仅有一个验证样本，结果只能演示算法；真实停止设置需要更可靠的验证集，独立测试集留到最终评估。若要继续训练，还需恢复相应优化器状态。

</details>

<details>
<summary>16. 保留独立测试：同一网络 → 测试损失</summary>

```text
恢复验证选中的第 4 次更新参数，保持固定。

新增测试样本 1：x = [2.5, 0.5]ᵀ，y = 7
新增测试样本 2：x = [0.5, 2.5]ᵀ，y = 3

仍执行原来的完整前向计算：
z = Wx + b；u = Ax + c
h = SiLU(z) ⊙ u；ŷ = vᵀh

样本 1：预测 4.8646，目标 7
平方误差 ≈ 4.5598

样本 2：预测 4.6283，目标 3
平方误差 ≈ 2.6514

Ltest = 两个平方误差的平均值
      ≈ 3.6056
```

测试损失的公式没有变，改变的是数据的用途。它们没有参与梯度更新、早停或检查点选择；测试过程中也不更新参数或优化器状态。

</details>

<details>
<summary>17. 报告最终结果与适用范围</summary>

```text
最终使用第 4 次更新后的同一组参数：
训练集：2 个样本，平均损失 ≈ 0.889285
验证集：1 个样本，损失 ≈ 4.227e-7
测试集：2 个样本，平均损失 ≈ 3.605556

训练集 → 学参数
验证集 → 选设置、选检查点

```

验证样本拟合得很好，也不代表其它样本都能做好。这个极小教学数据集不能可靠估计真实泛化水平。若看了测试结果后又据此调模型，便不能继续把同一测试集当作未参与开发的最终检验。

<summary>18. 新增：只提供新输入，不提供目标 y</summary>

```text
新输入：x = [1.8, 1.2]ᵀ
不提供目标 y

加载第 4 次更新后保存的：
W、A、b、c、v
共 14 个已训练参数

模型参数保持固定
不需要 AdamW 的 m、s，也不需要学习率 η
```

推理只使用学好的网络参数。若要恢复训练，则还要保存和加载优化器状态等信息。此处仅演示推理流程；前面的测试结果不代表这个小模型已经达到实际部署要求。

</details>

<details>
<summary>19. 前向推理 → 返回预测，结束</summary>

```text
沿用相同的前向计算：

z = Wx + b ≈ [4.7982, -0.9156]ᵀ
u = Ax + c ≈ [1.0562, 1.1937]ᵀ
SiLU(z) ≈ [4.7590, -0.2617]ᵀ
h = SiLU(z) ⊙ u ≈ [5.0264, -0.3124]ᵀ

```

推理完成不等于预测正确；没有标准答案时，不能仅凭输出判断误差。这 16 步完成的是简化网络的训练与使用流程。真正的语言模型还需要讲解 token、embedding、attention 和预测下一个 token 的训练目标。
